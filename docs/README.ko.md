# Galaxy Assistant 사용 안내

## 준비

1. Windows PC에서 `adb`를 설치하거나 배치 파일과 같은 폴더에 둡니다.
2. 휴대전화에서 **설정 → 휴대전화 정보 → 소프트웨어 정보**로 이동합니다.
3. **빌드번호**를 7번 눌러 개발자 옵션을 활성화합니다.
4. **설정 → 개발자 옵션 → USB 디버깅**을 켭니다.
5. USB로 연결한 뒤 휴대전화에 표시되는 디버깅 허용 창을 승인합니다.

## 실행

`galaxy-assistant-ko.bat`를 실행하고 메뉴 번호를 입력합니다.

- `1`: USB 디버깅 안내
- `2`: 카메라 셔터음 설정 비활성화
- `3`: 카메라 셔터음 설정 복원
- `4`: 배터리 정보 확인
- `5`: 공식 Camsung 1.2.1 APK 다운로드·검증·설치
- `6`: 종료

## Camsung 설치

메뉴 `5`는 [Camsung 공식 GitHub 저장소](https://github.com/ericswpark/camsung)의 1.2.1 APK를 내려받습니다. 배포자가 공개한 SHA-256과 일치하는지 확인한 후에만 설치하며, Android 14 이상에서는 필요한 `--bypass-low-target-sdk-block` 옵션을 자동으로 사용합니다.

설치가 끝나면 휴대전화에서 Camsung을 열고 스위치를 켭니다. 부팅할 때마다 다시 적용하려면 잠금 아이콘을 누릅니다. 카메라 무음 기능을 사용할 때는 휴대전화를 진동 또는 무음 모드로 설정해야 합니다.

## 주의사항

- 시스템 업데이트 후 설정이 초기화될 수 있습니다.
- 펌웨어와 지역 규정에서 허용하는 기기에서만 적용됩니다.
- 지원되는 기기에서도 진동 또는 무음 모드가 필요할 수 있습니다.
- 배터리 수명과 사이클 값은 일부 모델에서 제공되지 않을 수 있습니다.
